## 1. 项目简介

CAN/UDS 车载总线诊断工具是一款基于 Qt6/C++17 开发的跨平台车载总线分析与诊断软件，支持 CAN 总线报文监听、DBC 信号解析、UDS 诊断协议交互等核心功能。

### 核心特性

- **四层架构设计**：GUI层 → 业务编排层 → 核心协议层 → 硬件抽象层
- **自研协议栈**：完整实现 ISO-TP（ISO 15765-2）多帧传输和 UDS（ISO 14229）诊断协议
- **策略模式**：可插拔适配器架构，支持虚拟适配器、SocketCAN，可扩展 PCAN/ZLG 等硬件
- **DBC 解析**：支持标准 DBC 文件，自动解析信号定义、物理值转换、枚举值
- **8大功能面板**：报文追踪、信号波形、UDS诊断、信号数值、统计分析、报文发送、回放、配置
- **零硬件依赖**：内置虚拟适配器模拟 ECU，无需任何硬件即可完整体验全部功能

### 适用场景

- 车载网络开发与调试
- ECU 诊断与刷写
- CAN 总线报文分析
- DBC 信号验证
- 车载网络教学与学习

## 3. 安装说明

### Windows 安装

1. 双击运行 `CAN_UDS_Diagnostic_Tool_v1.1.0_Setup.exe`
2. 阅读许可协议，点击「我接受」
3. 选择安装路径（默认：`C:\Program Files\CAN-UDS-Diagnostic-Tool`）
4. 选择是否创建桌面快捷方式
5. 点击「安装」，等待安装完成
6. 点击「完成」，可选择立即运行软件

### 卸载方法

- 方法一：开始菜单 → CAN/UDS 诊断工具 → 卸载
- 方法二：控制面板 → 程序和功能 → 找到「CAN/UDS 车载总线诊断工具」→ 卸载
- 方法三：进入安装目录，运行 `unins000.exe`

### 绿色版使用（无需安装）

如果下载的是压缩包版本：
1. 解压到任意目录
2. 确保目录下包含 `can_uds_tool.exe` 和所有 Qt 运行时 DLL
3. 双击 `can_uds_tool.exe` 直接运行

## 4. 快速开始

### 4.1 首次启动（虚拟适配器模式，零硬件依赖）

1. 启动软件，主界面自动加载
2. 在「配置面板」中，适配器类型选择「虚拟适配器（模拟ECU）」
3. 波特率保持默认 `500000`
4. 点击工具栏的「启动」按钮（或按 `F5`）
5. 软件自动连接虚拟适配器，开始接收模拟报文

启动后你将看到：
- **报文追踪面板**：实时滚动显示 0x100、0x200 等周期报文
- **统计面板**：实时更新总线负载率、报文计数、ID 分布
- **状态栏**：显示「已连接 - 虚拟适配器」和实时统计

### 4.2 加载 DBC 文件查看信号

1. 点击菜单「文件 → 加载DBC」（或工具栏「加载DBC」按钮）
2. 选择示例文件 `sample.dbc`（位于安装目录）
3. 加载成功后，状态栏显示「DBC已加载: sample.dbc (X条报文, Y个信号)」
4. 切换到「信号波形面板」，选择信号查看实时波形
5. 切换到「信号数值面板」，查看所有信号的当前物理值

### 4.3 发送 UDS 诊断指令

1. 确保已启动虚拟适配器
2. 切换到「UDS诊断面板」
3. 设置诊断 ID：TX ID = `0x7E0`，RX ID = `0x7E8`
4. 点击「会话控制」→ 选择「扩展会话」→ 点击「发送」
5. 诊断日志显示请求和响应：`TX: 02 10 03 ...` → `RX: 06 50 03 ...`
6. 点击「读DID」→ 输入 `0xF190`（VIN）→ 点击「发送」
7. 响应中显示模拟 VIN：`TESTVIN1234567890`

### 4.4 停止运行

1. 点击工具栏的「停止」按钮（或按 `F6`）
2. 软件断开适配器连接，停止接收报文
3. 状态栏显示「已断开」

## 6. 功能面板详解

### 6.1 报文追踪面板（Trace Panel）

**功能**：实时显示总线上所有 CAN 报文，支持过滤、搜索、暂停、导出。

**列说明**：

| 列名 | 说明 |
|------|------|
| 时间戳 | 报文接收时间（秒，精确到微秒） |
| 方向 | RX（接收）/ TX（发送） |
| ID | 报文ID（十六进制） |
| 格式 | 标准帧(11位) / 扩展帧(29位) |
| DLC | 数据长度（0-8字节） |
| 数据 | 报文数据（十六进制，空格分隔） |
| 周期 | 同ID报文的平均周期（ms） |

**操作**：

- **过滤**：在顶部过滤框输入ID，如 `0x123` 或 `123, 0x456`，支持逗号分隔多个ID
- **暂停滚动**：点击「暂停」按钮，停止自动滚动（仍在后台接收）
- **清空**：点击「清空」按钮，清除所有显示的报文
- **导出**：右键 → 导出为CSV，保存当前显示的报文
- **颜色标记**：不同ID自动分配不同颜色，便于区分

**快捷键**：
- `Ctrl+F`：聚焦过滤框
- `Space`：暂停/继续滚动
- `Ctrl+L`：清空

### 6.2 信号波形面板（Signal Panel）

**功能**：将 DBC 解析后的信号以波形图实时显示，支持多信号叠加、缩放、暂停。

**操作**：

- **选择信号**：左侧信号列表勾选要显示的信号
- **信号过滤**：在搜索框输入信号名关键词过滤
- **缩放**：鼠标滚轮缩放时间轴，拖拽平移
- **暂停**：点击「暂停」按钮，冻结当前波形
- **重置视图**：点击「重置」按钮，恢复默认缩放
- **数值显示**：鼠标悬停在波形上显示当前点的时间和数值

**显示设置**：
- Y轴自动缩放 / 固定范围
- 显示网格线
- 显示信号图例
- 波形颜色自定义

### 6.3 UDS诊断面板（Diag Panel）

**功能**：发送 UDS 诊断请求，查看 ECU 响应，支持7种诊断服务。

**配置区**：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| TX ID | 诊断请求发送ID | 0x7E0 |
| RX ID | 诊断响应接收ID | 0x7E8 |
| 超时时间 | 请求超时（毫秒） | 3000 |
| 扩展帧 | 是否使用29位扩展ID | 关闭 |

**诊断服务**：

1. **会话控制（0x10）**
   - 选择会话类型：默认会话(0x01) / 扩展会话(0x03) / 编程会话(0x02)
   - 点击「发送」

2. **读DID（0x22）**
   - 输入DID，如 `0xF190`（VIN）
   - 支持连续读取多个DID（逗号分隔）
   - 点击「发送」

3. **写DID（0x2E）**
   - 输入DID和数据（十六进制，空格分隔）
   - 点击「发送」

4. **例程控制（0x31）**
   - 选择操作：启动例程(0x01) / 停止例程(0x02) / 查询结果(0x03)
   - 输入例程ID(RID)和参数
   - 点击「发送」

5. **ECU复位（0x11）**
   - 选择复位类型：硬复位(0x01) / 软复位(0x03) / 使能快速上电(0x04)
   - 点击「发送」

6. **TesterPresent（0x3E）**
   - 点击「发送」保活帧
   - 可勾选「自动发送」，每2秒自动发送一次

7. **安全访问（0x27）**
   - 输入安全级别（奇数，如0x01）
   - 点击「请求种子」
   - 输入密钥（或通过密钥计算回调自动生成）
   - 点击「发送密钥」
   - 状态显示：未解锁 / 等待种子 / 等待密钥确认 / 已解锁

**诊断日志区**：
- 显示所有请求和响应的原始数据
- 请求显示为 `TX: [时间] 数据`
- 响应显示为 `RX: [时间] 数据`
- 否定响应(NRC)用红色标记，并显示NRC含义
- 支持清空、导出、自动滚动

**常用NRC（否定响应码）**：

| NRC | 含义 |
|-----|------|
| 0x10 | 通用拒绝 |
| 0x11 | 服务不支持 |
| 0x12 | 子功能不支持 |
| 0x13 | 消息格式错误 |
| 0x22 | 条件不满足 |
| 0x24 | 请求序列错误 |
| 0x31 | 请求超出范围 |
| 0x33 | 安全访问被拒绝 |
| 0x35 | 密钥无效 |
| 0x36 | 超过尝试次数 |
| 0x78 | 请求已接收，响应未就绪 |

### 6.4 信号数值面板（Signal Value Panel）

**功能**：以表格形式显示所有 DBC 信号的当前值、单位、原始值、更新时间。

**列说明**：

| 列名 | 说明 |
|------|------|
| 报文名 | 信号所属报文名称（DBC中定义） |
| 信号名 | 信号名称 |
| 当前值 | 物理值（已转换，带单位） |
| 原始值 | 原始十六进制值 |
| 单位 | 信号单位（如 km/h, ℃, rpm） |
| 更新时间 | 最后一次更新的时间戳 |

**操作**：
- **过滤**：在顶部搜索框输入信号名或报文名过滤
- **排序**：点击列标题排序
- **高亮变化**：值变化时短暂高亮显示
- **导出**：右键 → 导出当前快照为CSV

### 6.5 统计分析面板（Stats Panel）

**功能**：实时统计总线状态，包括负载率、报文计数、ID分布、错误统计。

**统计项**：

| 指标 | 说明 |
|------|------|
| 总线负载率 | 当前总线使用率（%），基于波特率和实际数据量计算 |
| 接收报文数 | 启动以来接收的总报文数 |
| 发送报文数 | 启动以来发送的总报文数 |
| 唯一ID数 | 总线上出现过的不同ID数量 |
| 报文速率 | 当前每秒接收报文数（msg/s） |
| 数据速率 | 当前每秒数据字节数（B/s） |

**ID分布表**：
- 按ID统计每个ID的报文数、占比、平均周期
- 支持按报文数/周期/ID排序
- 占比用进度条可视化

**图表**：
- 负载率实时曲线图（最近60秒）
- 报文速率柱状图
- ID分布饼图

### 6.6 报文发送面板（Send Panel）

**功能**：手动发送自定义 CAN 报文，支持周期发送、单次发送、发送列表。

**单次发送**：
- 输入ID（十六进制，如 `0x123`）
- 选择标准帧/扩展帧
- 输入数据（十六进制，空格分隔，最多8字节）
- 点击「发送」

**周期发送**：
- 设置发送周期（ms，最小10ms）
- 点击「开始」持续发送，点击「停止」结束
- 可同时启用多个周期发送任务

**发送列表**：
- 预定义多条报文，可批量发送
- 支持导入/导出发送列表（JSON格式）
- 每条报文可单独启用/禁用

### 6.7 回放面板（Replay Panel）

**功能**：加载之前录制的日志文件，按原始时间顺序回放报文。

**操作**：
1. 点击「加载日志」，选择 `.log` 或 `.csv` 文件
2. 日志信息显示：报文总数、时间范围、ID数量
3. 设置回放速度：0.25x / 0.5x / 1x / 2x / 4x / 8x
4. 点击「播放」开始回放
5. 可暂停、继续、停止、拖动进度条跳转
6. 回放的报文会同时显示在报文追踪面板和信号面板

**支持的日志格式**：
- 本软件录制的 `.log` 格式（时间戳,方向,ID,DLC,数据）
- CSV格式（逗号分隔，首行为表头）
- Candump格式（Linux can-utils）

### 6.8 配置面板（Config Panel）

**功能**：配置适配器参数、过滤规则、显示选项。

**适配器配置**：

| 参数 | 说明 |
|------|------|
| 适配器类型 | 虚拟适配器 / SocketCAN / 自定义适配器 |
| 接口名称 | 适配器接口标识（如 vcan0, can0） |
| 波特率 | CAN总线速率：125k / 250k / 500k / 1M |
| 模拟ECU | 虚拟适配器专用，启用后自动响应UDS请求 |

**过滤配置**：
- 过滤模式：不过滤 / 白名单（仅显示列表中的ID） / 黑名单（隐藏列表中的ID）
- 过滤ID列表：逗号分隔，如 `0x123, 0x456, 0x7E0`
- 支持掩码过滤：`0x700:0xF00`（匹配0x700-0x7FF）

**显示选项**：
- 时间戳格式：相对时间 / 绝对时间
- 数据显示：十六进制 / 十进制
- 自动滚动：开启/关闭
- 最大显示报文数：默认10000条（超出自动清除最早的）

## 8. UDS诊断操作指南

### 8.1 诊断流程概述

UDS（统一诊断服务，ISO 14229）是车载ECU诊断的标准协议。典型诊断流程：

```
1. 建立连接 → 启动CAN总线
2. 切换会话 → 0x10 扩展会话
3. 安全访问 → 0x27 请求种子 → 计算密钥 → 发送密钥（可选）
4. 诊断操作 → 读DID / 写DID / 例程控制 / 读写内存
5. 保活 → 0x3E TesterPresent（保持会话不超时）
6. 结束 → 0x11 ECU复位 或 切换回默认会话
```

### 8.2 读取VIN示例

1. 启动虚拟适配器
2. UDS诊断面板设置 TX=0x7E0, RX=0x7E8
3. 点击「会话控制」→ 选择「扩展会话(0x03)」→ 发送
4. 响应：`06 50 03 00 32 01 F4`（50=10+40正响应，03=回显会话）
5. 点击「读DID」→ 输入 `0xF190` → 发送
6. 响应：`10 14 62 F1 90 54 45 53`（首帧，总长度20字节）
   → 软件自动发送流控帧
   → 接收连续帧，重组完整数据
7. 完整响应数据：`62 F1 90 54 45 53 54 56 49 4E 31 32 33 34 35 36 37 38 39 30`
8. 解析：62=正响应，F190=DID，后续17字节=ASCII "TESTVIN1234567890"

### 8.3 安全访问示例

1. 切换到扩展会话
2. 安全访问区输入级别 `0x01`
3. 点击「请求种子」
4. 响应：`06 67 01 12 34 56 78`（67=27+40，01=级别，12345678=种子）
5. 软件根据密钥计算回调（或手动输入）计算密钥
6. 点击「发送密钥」
7. 响应：`02 67 01`（正响应，解锁成功）
8. 状态显示「已解锁 - Level 1」

### 8.4 多帧传输说明

当UDS请求或响应数据超过7字节时，ISO-TP协议自动进行多帧传输：

- **单帧(SF)**：数据≤7字节，一帧完成
- **首帧(FF)**：数据>7字节，第一帧包含总长度和前6字节数据
- **连续帧(CF)**：后续帧，每帧最多7字节数据，带序号
- **流控帧(FC)**：接收方发送，告知发送方继续发送的节奏（BS块大小、STmin最小间隔）

软件自动处理所有多帧传输，用户无需手动干预。诊断日志中会显示完整的重组后数据。

### 8.5 虚拟ECU支持的DID

| DID | 含义 | 返回数据 |
|-----|------|---------|
| 0xF190 | VIN（车辆识别码） | "TESTVIN1234567890" (17字节ASCII) |
| 0xF18E | 硬件版本 | "HW_V1.0.0" |
| 0xF18A | 软件版本 | "SW_V2.3.1" |
| 0xF18C | 供应商代码 | "VIRTUAL" |
| 0x1234 | 自定义数据 | 12 34 56 78 |
| 其他 | 未定义 | 00 00 |

## 9. DBC文件使用

### 9.1 什么是DBC文件

DBC是Vector公司定义的CAN数据库文件格式，用于描述CAN总线上的报文和信号定义，是车载网络开发的标准格式。

### 9.2 DBC文件结构

```
VERSION "1.0"

NS_ :  （网络节点定义）
    BU_  （节点）
    BO_  （报文）
    SG_  （信号）
    EV_  （环境变量）

BU_ : ECM BCM TCM  （节点列表）

BO_ 256 EngineData: 8 ECM  （报文ID=256(0x100)，名称EngineData，8字节，发送节点ECM）
 SG_ EngineSpeed : 0|16@0+ (1,0) [0|8000] "rpm" TCM  （信号定义）
 SG_ EngineTemp : 16|16@0+ (0.1,-40) [-40|215] "℃" BCM
 SG_ VehicleSpeed : 32|16@0+ (0.01,0) [0|300] "km/h" TCM

BO_ 512 VehicleStatus: 8 BCM
 SG_ DoorStatus : 0|4@0+ (1,0) [0|15] "" ECM
 SG_ LightStatus : 4|4@0+ (1,0) [0|15] "" ECM

VAL_ 512 DoorStatus 0 "关闭" 1 "打开" 2 "未关严" ;  （枚举值定义）
```

### 9.3 信号定义格式说明

`SG_ SignalName : startBit|length@byteOrder+/- (factor,offset) [min|max] "unit" receiver`

| 字段 | 说明 |
|------|------|
| SignalName | 信号名称 |
| startBit | 起始位（0-63） |
| length | 位长度（1-64） |
| byteOrder | @0=大端(Motorola)，@1=小端(Intel) |
| +/- | +=无符号，-=有符号 |
| factor | 缩放系数 |
| offset | 偏移量 |
| min/max | 物理值范围 |
| unit | 单位 |
| receiver | 接收节点 |

**物理值计算公式**：`物理值 = 原始值 × factor + offset`

### 9.4 加载DBC

1. 菜单「文件 → 加载DBC」或工具栏按钮
2. 选择 `.dbc` 文件
3. 软件自动解析：
   - 所有报文定义（BO_）
   - 所有信号定义（SG_）
   - 枚举值表（VAL_）
   - 节点定义（BU_）
4. 加载成功后状态栏显示统计信息
5. 信号波形面板和信号数值面板自动显示解析后的信号

### 9.5 示例DBC文件

安装目录下的 `sample.dbc` 包含示例报文定义，与虚拟适配器的模拟报文对应：

| 报文ID | 报文名 | 信号 |
|--------|--------|------|
| 0x100 | EngineData | EngineSpeed(转速), EngineTemp(温度), VehicleSpeed(车速) |
| 0x200 | VehicleStatus | DoorStatus(车门), LightStatus(灯光), FuelLevel(油量) |

## 11. 常见问题

### Q1: 启动后没有报文显示？

**A**: 检查以下几点：
1. 确认已点击「启动」按钮，状态栏显示「已连接」
2. 虚拟适配器模式下，确认「模拟ECU」选项已开启
3. 检查配置面板的过滤设置，确认不是白名单/黑名单过滤掉了所有报文
4. 尝试点击「清空」按钮，看是否有新报文进来
5. SocketCAN模式下，确认接口已配置：`sudo ip link set vcan0 up type can bitrate 500000`

### Q2: 加载DBC后信号面板没有数据？

**A**: 
1. 确认DBC加载成功，状态栏显示DBC信息
2. 确认总线上有与DBC中定义的ID匹配的报文
3. 虚拟适配器的模拟报文ID是0x100和0x200，确认DBC中有对应定义
4. 检查信号起始位和位长度是否正确
5. 尝试在报文追踪面板查看原始数据，确认报文在接收

### Q3: UDS诊断没有响应？

**A**:
1. 确认CAN总线已启动
2. 确认TX ID和RX ID设置正确（虚拟适配器默认TX=0x7E0, RX=0x7E8）
3. 虚拟适配器模式下，确认「模拟ECU」已开启
4. 检查诊断日志，看请求是否发送成功
5. 如果发送了请求但没有响应，可能是ECU不支持该服务或需要先切换会话
6. 尝试先发送「会话控制 → 扩展会话」，再发送其他诊断指令

### Q4: 软件崩溃或无法启动？

**A**:
1. 确认安装目录下所有DLL文件完整（不要单独复制exe）
2. 确认操作系统是64位
3. 尝试以管理员身份运行
4. 检查是否被杀毒软件拦截
5. 查看安装目录下是否有崩溃日志文件
6. 重新安装软件

### Q5: 任务栏遮挡窗口底部？

**A**: 
1. 软件启动时自动最大化，会自动避开任务栏
2. 如果手动调整了窗口大小，双击标题栏重新最大化
3. 或菜单「视图 → 全屏模式」(F11)

### Q6: 如何连接真实CAN硬件？

**A**:
1. 当前版本内置虚拟适配器和Linux SocketCAN适配器
2. Windows平台连接PCAN/ZLG/USB-CAN等硬件，需要开发对应适配器
3. 开发方法：继承 `CanAdapterBase` 类，实现 `open/close/sendFrame/isOpen/adapterName` 五个纯虚函数
4. 在配置面板选择自定义适配器
5. 参考 `docs/04_硬件抽象层与业务编排层.md` 中的适配器开发指南

### Q7: 录制的日志文件在哪里？

**A**:
1. 开始录制时会弹出文件保存对话框，你选择的路径就是保存位置
2. 默认文件名格式：`can_log_YYYYMMDD_HHMMSS.log`
3. 如果忘记了保存位置，可以在菜单「文件 → 最近录制」中查看历史记录

### Q8: 支持CAN FD吗？

**A**: 当前版本(v1.1.0)不支持CAN FD（64字节数据域），仅支持经典CAN（8字节数据域）。CAN FD支持已列入v1.5版本规划。

### Q9: 支持哪些UDS服务？

**A**: 当前版本支持7种核心UDS服务：
- 0x10 诊断会话控制
- 0x22 读数据标识符
- 0x2E 写数据标识符
- 0x31 例程控制
- 0x11 ECU复位
- 0x3E TesterPresent
- 0x27 安全访问

更多服务（0x23读内存、0x34/36/37数据传输、0x38文件传输等）已列入v2.0版本规划。

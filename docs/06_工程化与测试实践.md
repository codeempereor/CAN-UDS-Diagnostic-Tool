# 06 — 工程化与测试实践

## 6.1 测试体系总览

### 三层测试架构

```
┌─────────────────────────────────────────────────┐
│              系统测试 (System Test)               │
│  真实硬件在环 / 实车诊断验证 / 端到端功能测试     │
├─────────────────────────────────────────────────┤
│              集成测试 (Integration Test)          │
│  适配器+协议层联调 / 虚拟CAN总线回环 / 模块交互   │
├─────────────────────────────────────────────────┤
│              单元测试 (Unit Test)                 │
│  协议层函数级测试 / 边界条件 / 异常处理 / 状态机   │
└─────────────────────────────────────────────────┘
```

### 测试原则

1. **核心协议层100%覆盖**：CAN/DBC/ISO-TP/UDS所有关键函数必须有测试用例
2. **测试即文档**：测试用例同时作为函数使用示例和行为规范
3. **自动化执行**：所有测试集成到CTest，CI自动运行
4. **边界优先**：优先测试边界条件、异常输入、状态转换

## 6.2 单元测试详解

### 测试框架

自研轻量级单元测试框架，基于断言宏，零依赖，单头文件实现：

```cpp
// tests/test_framework.h
#pragma once
#include <cstdio>
#include <cstring>

static int g_test_count = 0;
static int g_test_pass = 0;
static int g_test_fail = 0;

#define TEST_CASE(name) \
    static void name(); \
    static struct name##_registrar { \
        name##_registrar() { \
            g_test_count++; \
            printf("[TEST] %s\n", #name); \
            name(); \
        } \
    } name##_instance; \
    static void name()

#define ASSERT_EQ(expected, actual) \
    do { \
        if ((expected) == (actual)) { \
            g_test_pass++; \
        } else { \
            g_test_fail++; \
            printf("  [FAIL] %s:%d: expected %d, got %d\n", \
                __FILE__, __LINE__, (int)(expected), (int)(actual)); \
        } \
    } while(0)

#define ASSERT_TRUE(cond) \
    do { \
        if (cond) { g_test_pass++; } \
        else { g_test_fail++; printf("  [FAIL] %s:%d: condition false\n", __FILE__, __LINE__); } \
    } while(0)
```

#### CAN过滤器测试（4项）

```cpp
TEST_CASE(can_filter_whitelist)
{
    CanFilter filter;
    filter.setMode(CanFilter::Whitelist);
    filter.addId(0x100);
    filter.addId(0x200);
    
    ASSERT_TRUE(filter.accept(0x100));   // 白名单内，通过
    ASSERT_TRUE(filter.accept(0x200));   // 白名单内，通过
    ASSERT_TRUE(!filter.accept(0x300));  // 白名单外，拒绝
}

TEST_CASE(can_filter_mask)
{
    CanFilter filter;
    filter.setMode(CanFilter::Mask);
    filter.addMask(0x700, 0x100);  // 匹配0x100~0x1FF
    
    ASSERT_TRUE(filter.accept(0x150));   // 掩码匹配，通过
    ASSERT_TRUE(!filter.accept(0x250));  // 掩码不匹配，拒绝
}
```

#### DBC位提取测试（7项，边界优先）

```cpp
TEST_CASE(dbc_bit_extract_8bit)
{
    uint8_t data[8] = {0xFF, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00};
    uint64_t value = DbcSignal::extractBits(data, 0, 8, DbcSignal::Intel);
    ASSERT_EQ(0xFF, value);  // 8位全1
}

TEST_CASE(dbc_bit_extract_cross_byte)
{
    uint8_t data[8] = {0xAB, 0xCD, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00};
    uint64_t value = DbcSignal::extractBits(data, 4, 12, DbcSignal::Intel);
    ASSERT_EQ(0xDAB, value);  // 跨字节提取：低4位0xB + 高8位0xDA
}

TEST_CASE(dbc_bit_extract_motorola_big_endian)
{
    uint8_t data[8] = {0x12, 0x34, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00};
    uint64_t value = DbcSignal::extractBits(data, 0, 16, DbcSignal::Motorola);
    ASSERT_EQ(0x1234, value);  // Motorola大端
}
```

**历史bug修复验证**：大端位提取跨字节越界bug，通过7个边界测试用例验证修复正确性。

#### ISO-TP状态机测试（3项）

```cpp
TEST_CASE(isotp_single_frame)
{
    IsoTpClient client;
    client.setReceiveCallback([](const uint8_t* data, int len) {
        ASSERT_EQ(5, len);
        ASSERT_EQ(0x22, data[0]);
    });
    
    uint8_t frame[8] = {0x05, 0x22, 0xF1, 0x90, 0x01, 0x02, 0x03, 0x04};
    client.handleReceivedFrame(frame, 8);  // SF单帧，PCI=0x05表示5字节数据
}

TEST_CASE(isotp_multi_frame_first_consecutive)
{
    IsoTpClient client;
    int received_len = 0;
    client.setReceiveCallback([&](const uint8_t* data, int len) {
        received_len = len;
    });
    
    // FF首帧：PCI=0x100E表示14字节数据
    uint8_t ff[8] = {0x10, 0x0E, 0x01, 0x02, 0x03, 0x04, 0x05, 0x06};
    client.handleReceivedFrame(ff, 8);
    
    // CF连续帧：PCI=0x21表示序列号1
    uint8_t cf[8] = {0x21, 0x07, 0x08, 0x09, 0x0A, 0x0B, 0x0C, 0x0D};
    client.handleReceivedFrame(cf, 8);
    
    ASSERT_EQ(14, received_len);  // 拼接后总长度14字节
}
```

#### UDS诊断服务测试（4项）

```cpp
TEST_CASE(uds_read_data_by_identifier)
{
    UdsClient client;
    client.setResponseCallback([](uint8_t service, const uint8_t* data, int len) {
        ASSERT_EQ(0x22, service);  // 正响应SID=0x62=0x22+0x40
        ASSERT_EQ(3, len);
    });
    
    // 模拟正响应：0x62 0xF1 0x90 0x01 0x02 0x03
    uint8_t response[8] = {0x62, 0xF1, 0x90, 0x01, 0x02, 0x03, 0x00, 0x00};
    client.handleReceivedFrame(response, 6);
}

TEST_CASE(uds_negative_response)
{
    UdsClient client;
    bool got_negative = false;
    client.setNegativeResponseCallback([&](uint8_t service, uint8_t nrc) {
        got_negative = true;
        ASSERT_EQ(0x22, service);
        ASSERT_EQ(0x31, nrc);  // requestOutOfRange
    });
    
    // 负响应：0x7F 0x22 0x31
    uint8_t response[3] = {0x7F, 0x22, 0x31};
    client.handleReceivedFrame(response, 3);
    
    ASSERT_TRUE(got_negative);
}
```

### C++17编码规范

| 规范项 | 要求 | 示例 |
|--------|------|------|
| **命名空间** | 模块级命名空间，全小写 | `namespace can { ... }` |
| **类名** | 大驼峰（PascalCase） | `class IsoTpClient` |
| **函数名** | 小驼峰（camelCase） | `void sendData(const uint8_t* data, int len)` |
| **成员变量** | m_前缀 + 小驼峰 | `std::deque<uint8_t> m_rxBuffer;` |
| **常量** | 全大写 + 下划线 | `constexpr int MAX_DATA_LEN = 4095;` |
| **枚举** | 枚举类，大驼峰 | `enum class FrameType : uint8_t { Single=0x0, First=0x1 };` |
| **指针** | 优先智能指针，裸指针需注释 | `std::unique_ptr<CanAdapterBase> m_adapter;` |
| **const正确性** | 不修改成员的函数必须加const | `int getLength() const { return m_length; }` |
| **异常安全** | RAII管理资源，关键操作try-catch | `std::lock_guard<std::mutex> lock(m_mutex);` |
| **魔法数字** | 协议常量定义为枚举或constexpr | `constexpr uint8_t UDS_NRC = 0x7F;` |

### Doxygen注释规范

```cpp
/**
 * @brief ISO-TP多帧传输客户端
 * 
 * 实现ISO 15765-2网络层协议，支持单帧/多帧传输、
 * 流控机制、超时检测、序列号验证。
 * 
 * @note 核心协议层，零Qt依赖，可移植到嵌入式平台
 */
class IsoTpClient {
public:
    /**
     * @brief 发送数据（自动判断单帧/多帧）
     * @param data 数据指针
     * @param len 数据长度（≤7单帧，>7多帧）
     * @return true 发送成功，false 发送失败
     */
    bool sendData(const uint8_t* data, int len);
    
    /**
     * @brief 处理接收到的CAN帧
     * @param frame CAN帧数据（8字节）
     * @param len 帧长度
     */
    void handleReceivedFrame(const uint8_t* frame, int len);
    
    /**
     * @brief 超时检查（需周期性调用，建议100ms）
     * @return true 有超时事件，false 正常
     */
    bool checkTimeout();
    
private:
    std::function<void(const uint8_t*, int)> m_receiveCallback;  ///< 接收完成回调
    std::deque<uint8_t> m_rxBuffer;     ///< 接收缓冲区（多帧拼接）
    int m_rxExpectedLen;                 ///< 期望接收总长度（FF中指定）
    uint8_t m_rxSequence;                ///< 接收期望序列号
    std::chrono::steady_clock::time_point m_lastFrameTime;  ///< 最后帧时间戳
};
```

## 6.6 构建系统

### CMake分层构建

```cmake
# CMakeLists.txt
cmake_minimum_required(VERSION 3.16)
project(can_uds_tool VERSION 1.0.0 LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_AUTOMOC ON)
set(CMAKE_AUTORCC ON)

# 选项
option(BUILD_TESTS "Build unit tests" ON)
option(ENABLE_COVERAGE "Enable code coverage" OFF)

# Qt5/6自动检测
find_package(Qt6 QUIET COMPONENTS Core Gui Widgets)
if(NOT Qt6_FOUND)
    find_package(Qt5 REQUIRED COMPONENTS Core Gui Widgets)
    set(QT_VERSION_MAJOR 5)
else()
    set(QT_VERSION_MAJOR 6)
endif()

# 核心协议层（纯C++，无Qt依赖）
add_subdirectory(src/core)

# 硬件抽象层
add_subdirectory(src/hal)

# 业务编排层（Qt Core）
add_subdirectory(src/business)

# GUI层（Qt Widgets）
add_subdirectory(src/gui)

# 单元测试
if(BUILD_TESTS)
    enable_testing()
    add_subdirectory(tests)
endif()
```

## 6.7 CI/CD与开源管理

### GitHub Actions CI

双平台自动构建测试矩阵：

```yaml
# .github/workflows/ci.yml
name: CI
on: [push, pull_request]

jobs:
  build:
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest]
        qt_version: ['6.5.0']
    runs-on: ${{ matrix.os }}
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Install Qt
        uses: jurplel/install-qt-action@v3
        with:
          version: ${{ matrix.qt_version }}
          modules: qtbase
      
      - name: Configure
        run: cmake -B build -DBUILD_TESTS=ON
      
      - name: Build
        run: cmake --build build --config Release
      
      - name: Test
        run: ctest --test-dir build --output-on-failure
      
      - name: Upload artifact
        uses: actions/upload-artifact@v4
        with:
          name: can_uds_tool_${{ matrix.os }}
          path: build/bin/
```
